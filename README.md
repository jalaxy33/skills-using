# Skills Using

This repo contains skills I'm using. 


## How to use

- (Optional) Backup your `~/.agents`:

  ```sh
  mv ~/.agents ~/.agents-bak
  ```

- Clone it to `~/.agents`:

  ```sh
  git clone https://github.com/jalaxy33/skills-using ~/.agents
  ```

- Update skills to latest using `npx skills`:
  
  ```sh
  npx skills update -g
  ```
